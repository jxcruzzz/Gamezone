## 🎮 GameZone - Sitio Web de Videojuegos
Proyecto web desarrollado para la materia de Plataformas Abiertas II, demostrando el uso de React con Vite, componentes reutilizables y múltiples funcionalidades interactivas.

## 📋 Características
# 🎯 Páginas
Inicio	    Landin page con presentación y cards de características
Nosotros	Información de la empresa y mision, vision y valores
Servicios	Servicios ofrecidos con precios y cards de carateristicas
Galería	    Catálogo de 6 videojuegos 
Noticias    Cards con noticias de ultimo momento
Contacto	Formulario de contacto con validación y mensaje de éxito

## 🎮 Funcionalidades
# 🔍 Sistema de Búsqueda y Filtros
Filtrado por categoría (Aventura, RPG, Deportes, Shooter, Sandbox, Battle Royale)
Mensaje dinámico cuando no hay resultados

## 📱 Menú Responsive
Botón hamburguesa para dispositivos móviles
Navegación intuitiva con React Router
Enlaces activos con estilo diferenciado

## ✅ Validación de Formularios
# Validación de campos requeridos (nombre, email, mensaje)
Validación básica de email
Mensaje de éxito dinámico al enviar

## 🃏 Componentes Interactivos
# Tarjetas con hover effect (transform y sombra)
Botones con variantes (primario, secundario)
Alertas dinámicas de éxito/error

## 🛠️ Tecnologías Utilizadas
React	
Vite	
React Router DOM	
CSS3	
JavaScript (ES6+)	
API

## Características técnicas:
✅ Componentes reutilizables con props
✅ useState para manejo de estado
✅ useEffect para manejo de estado
✅ CSS por componente
✅ Diseño responsive con Media Queries

## 📸 Galería de Videojuegos
# La galería incluye 6 videojuegos con:
Nombre del juego
Imagen representativa
Descripción corta
Precio
Categoría
Botón "Ver más"

## Funcionalidades de la galería:
🏷️ Filtrado por categoría
📱 Diseño responsive en grid

## Como ejecutarlo
# 1. Clonar el repositorio
git clone 

# 2. Entrar a la carpeta del proyecto
cd vite-project

# 3. Instalar dependencias
npm install

# 4. Iniciar el servidor de desarrollo
npm run dev

# 5. Abrir el navegador en
http://localhost:5173
